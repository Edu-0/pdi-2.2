# PDI — Trabalho M2

Implementação em `main.ipynb` dos Projetos 1 e 2 e da Opção 2 de Morfologia.

Instale as dependências no Python usado pelo notebook:

```sh
python -m pip install -r requirements.txt
```

Abra `main.ipynb` no VS Code ou Jupyter, selecione esse ambiente Python e execute as células em ordem. As imagens devem estar em `imgs/`, ao lado do notebook. Os resultados ficam exibidos no próprio notebook.

Os limites de cor, sementes, tolerâncias e tamanhos dos elementos estruturantes estão indicados nas respectivas seções para facilitar os experimentos. As imagens são reduzidas proporcionalmente para acelerar a execução; as sementes são informadas nas coordenadas originais e convertidas pelo código.

O relatório PDF e os slides solicitados no enunciado são entregas separadas; este repositório contém a implementação e sua discussão no notebook.
